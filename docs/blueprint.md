# **App Name**: bond

## Core Features:

- Basic Chat Interface: Simple chat interface: a straightforward way for users to send and receive messages.
- Online Status: Display other user's online status. Indication will be active or inactive
- User Profiles: Users can set up profile picture and name.
- Smart Replies: LLM analyses recent conversations, using it as a tool to offer context-aware smart reply suggestions.
- Authentication: Authentication to restrict the access to valid users.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6), evoking calmness and reliability, the feeling of a steady stream of information.
- Background color: Light grey (#F0F4F8), creating a clean and unobtrusive backdrop for conversation.
- Accent color: Muted teal (#4DB6AC), offering subtle contrast to highlight interactive elements without being jarring.
- Font: 'Inter', a grotesque sans-serif known for its readability and modern, neutral appearance, suitable for both headings and body text.
- Clean, minimalist icons for actions like sending messages and accessing user profiles.
- Clean, simple layout emphasizing readability and ease of navigation.
